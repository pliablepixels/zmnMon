What am I looking at?
ESTABLISHED active stream. Baseline; should track the number of open streams.
CLOSE_WAIT peer closed, the app has not. Rising and not draining = the leak (#150).
TIME_WAIT clean local close, clears in ~60s. Its presence means closes are happening.
SYN_SENT connecting, no reply yet. Many = server not responding.
FIN_WAIT_2 local closed, waiting on peer. Many = server not closing its end.
STUCK (CW+FIN_WAIT_2) sockets neither side cleaned up. The single line to watch.
Red shading CLOSE_WAIT is at or above the alert threshold.
LISTEN server sockets. Noise for this bug; hidden by default.
